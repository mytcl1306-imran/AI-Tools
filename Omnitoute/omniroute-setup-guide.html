01
Install OmniRoute
Requires Node.js v18+. Run once globally.

Open PowerShell or Command Prompt and run:

PowerShell 
PS > npm i -g omniroute
ℹ️ Don't have Node.js? Download it from nodejs.org (v18 or higher recommended).
02
Start the OmniRoute Server
Keep this terminal open the entire time.

In the same PowerShell window, run:

PowerShell 
PS > omniroute
⚠️ Do not close this window. OmniRoute must keep running in the background. For the next steps, open a new PowerShell window.

Then open your browser and go to:

Browser URL 
http://localhost:20128/home
03
Connect Your AI Providers
Go to Providers section in the web dashboard.

In the OmniRoute dashboard, click Providers in the left sidebar and add these four:

🔑 Antigravity Auth Login (OAuth)
🦙 Ollama API Key / Local
🌐 OpenRouter API Key
🪁 Kiro API Key
✅ Free providers like OpenCode Zen and SiliconFlow require no API key — add them too for maximum free quota!
04
Create Your Combo
Combine all providers into one smart route.

In the dashboard → Combos → Create New Combo. Chain providers in this order and name it omni_combo:

Combo Config 
Antigravity  ← Priority 1 (OAuth, subscription-level)
    ↓
Ollama       ← Priority 2 (local, free)
    ↓
OpenRouter   ← Priority 3 (API key fallback)
    ↓
Kiro         ← Priority 4 (final fallback)
    ↓
Model Name: omni_combo
ℹ️ OmniRoute will automatically fallback to the next provider if one hits a rate limit or fails.
05
Create an API Key in Dashboard
This is your OmniRoute auth token.

Go to API Keys in the left sidebar → Generate a new key → Copy it. You'll use this as YOUR_TOKEN_HERE in the next step.

💡 Generate one key per environment (e.g., "claude-code", "n8n", "dev"). Makes it easy to revoke individual tools later.
06
Set Environment Variables
Open a NEW PowerShell window for this step.

Run these commands in a new PowerShell window (replace YOUR_TOKEN_HERE with your actual key):

PowerShell 
$env:CLAUDE_CONFIG_DIR     = "$HOME\.claude-omniroute"
$env:ANTHROPIC_BASE_URL    = "http://localhost:20128"
$env:ANTHROPIC_AUTH_TOKEN  = "YOUR_TOKEN_HERE"
$env:ANTHROPIC_API_KEY     = ""
$env:ANTHROPIC_MODEL       = "omni_combo"
VariablePurpose
CLAUDE_CONFIG_DIRSeparate Claude config so it doesn't conflict with your main Claude install
ANTHROPIC_BASE_URLRedirects Claude to your local OmniRoute server
ANTHROPIC_AUTH_TOKENYour OmniRoute API key (from Step 5)
ANTHROPIC_API_KEYCleared so Claude doesn't try to hit Anthropic directly
ANTHROPIC_MODELTells Claude to use your custom omni_combo
07
Verify the Configuration
Confirm all variables are set correctly.

In the same PowerShell window, run:

PowerShell 
echo $env:CLAUDE_CONFIG_DIR
echo $env:ANTHROPIC_BASE_URL
echo $env:ANTHROPIC_MODEL

You should see:

Expected Output
C:\Users\YOUR_USERNAME\.claude-omniroute
http://localhost:20128
omni_combo
08
Make Settings Permanent (Optional)
So you don't have to re-run on every session.

To persist these variables permanently in Windows, run this in PowerShell (run as Administrator):

PowerShell (Admin) 
[System.Environment]::SetEnvironmentVariable("CLAUDE_CONFIG_DIR", "$HOME\.claude-omniroute", "User")
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_BASE_URL", "http://localhost:20128", "User")
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_AUTH_TOKEN", "YOUR_TOKEN_HERE", "User")
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_API_KEY", "", "User")
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_MODEL", "omni_combo", "User")
ℹ️ After running, restart PowerShell for changes to take effect.
09
Launch Claude Code!
Final step — run Claude through OmniRoute.
PowerShell 
PS > claude
🎉

Claude Code → OmniRoute → omni_combo

Claude is now routing through your local OmniRoute server with auto-fallback across Antigravity → Ollama → OpenRouter → Kiro. Monitor usage at localhost:20128/home.

Make Settings Permanent
Persist across all Terminal sessions via .zshrc

Step 1 — Open your .zshrc file:

Terminal / zsh 
nano ~/.zshrc

Step 2 — Add these lines at the bottom (paste as-is):

~/.zshrc — Add these lines 
export CLAUDE_CONFIG_DIR="$HOME/.claude-omniroute"
export ANTHROPIC_BASE_URL="http://localhost:20128"
export ANTHROPIC_AUTH_TOKEN="YOUR_TOKEN_HERE"
export ANTHROPIC_API_KEY=""
export ANTHROPIC_MODEL="omni_combo"

Step 3 — Save and exit nano:

Keyboard Shortcuts in nano
Save file:   Ctrl + O  →  press Enter
Exit nano:   Ctrl + X

Step 4 — Apply the changes immediately:

Terminal / zsh 
source ~/.zshrc
✅ From now on, every new Terminal window will automatically have the OmniRoute config loaded — no need to re-run export commands.
